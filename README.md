## 🚀 Как использовать для lpmotor.ru

### **Вариант 1: Прямая вставка кода**

1. Откройте файл `full-page.html` (или любой отдельный блок)
2. Скопируйте всё содержимое
3. В lpmotor.ru вставьте HTML-код в редактор
4. ✅ Готово! Все стили уже инлайн

### **Вариант 2: Публикация на GitHub Pages (РЕКОМЕНДУЕТСЯ)**

#### Шаг 1: Создайте репозиторий
```bash
# В терминале
git init
git add .
git commit -m "UMTK standalone export"
gh repo create umtk-export --public --source=. --push
```

#### Шаг 2: Включите GitHub Pages
1. Зайдите в Settings → Pages
2. Source: Deploy from branch → `main` → `/root`
3. Save

#### Шаг 3: Скопируйте URL
Через 1-2 минуты ваш сайт будет доступен по адресу:
```
https://ваш-username.github.io/umtk-export/export-standalone/full-page.html
```

#### Шаг 4: Импорт в lpmotor.ru
1. В lpmotor.ru выберите **"Импорт по URL"**
2. Вставьте ссылку на GitHub Pages
3. ✅ lpmotor автоматически импортирует стили и структуру!

## 🔧 Импорт в Figma через плагин

### Используйте плагин **html.to.design**

1. Откройте Figma
2. Plugins → Browse plugins → **html.to.design**
3. Выберите один из вариантов:
   - **Вставить URL** (если опубликовали на GitHub Pages)
   - **Вставить HTML** (скопируйте код из файла)
4. Плагин автоматически создаст фреймы с сохранением:
   - ✅ Всех отступов
   - ✅ Размеров шрифтов
   - ✅ Градиентов
   - ✅ Иконок (как SVG)

## 🆘 Troubleshooting

### Проблема: Градиенты не отображаются в lpmotor
**Решение:** Используйте метод "Импорт по URL" через GitHub Pages (Вариант 2)

### Проблема: Иконки выглядят некорректно
**Решение:** Все иконки уже инлайн SVG. Если они не отображаются, проверьте, что lpmotor поддерживает SVG.

### Проблема: Мобильная версия "ломается"
**Решение:** Убедитесь, что в `<head>` есть:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
(Уже включено во все файлы!)
